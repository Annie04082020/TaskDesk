# Task Desk (個人任務工作桌)

一個低壓力、高專注的個人任務管理工作桌。將腦袋中的想法快速倒入收集箱，並將任務精確分流為「這週」、「保溫」與「放生」三堆。

---

## 設計原則

1. **工具只呈現與限制，不指揮**：語氣維持客觀中性，不提供「你該去做了」等催促用語或遊戲化懲罰機制。
2. **決定權在使用者**：「現在做這個」由使用者主動指定，系統不強制排序或自動指派。
3. **降低開啟壓力**：預設僅展開「這週」的任務，其餘分類預設收合，點擊後才呈現。
4. **規則皆可自訂**：「這週」任務上限（預設 3 件，可自由增減）、分類標籤、狀態諮詢條件等皆可自訂。
5. **零後端、零付費服務**：資料皆存放於使用者裝置的本機儲存空間（LocalStorage），無資料外洩風險。

---

## 核心功能

### 1. 雙工作桌分流與任務容量限制
* **今日工作桌 (Today)**：專注當天要消化的行動，預設小任務容量限制（例如每天最多 3 件小任務）。
* **這週工作桌 (Week)**：掌控本週核心推進項目，預設中/大任務容量限制（例如本週最多 3 件中/大任務）。
* **現在做這個 (Now)**：可指派單一項目為「現在」，置頂凸顯避免分心。
* **分流專用夾**：
  * **收集箱 (Inbox)**：快速記錄未整理的靈感與待辦事項。
  * **保溫 (Keep)**：尚不急著執行、但保留追蹤的任務。
  * **放生 (Release)**：目前不打算執行或已暫停的事項，移出注意力範圍。

### 2. 完成任務歷史檔案庫 (History Archive)
* **永不遺失**：勾選完成的任務**絕不會被直接刪除**，而是自動永久歸檔至獨立的「歷史檔案庫」。
* **週別歸納與復原**：歷史檔案依據完成時間自動按週別摺疊整理，隨時可一鍵將任務復原回「今日」或「這週」工作桌。
* **資料匯出**：支援一鍵匯出為乾淨排版的 **Markdown 週報格式** 或完整的 **JSON 封存檔案**。

### 3. Android 桌面小工具 (Widgets)
針對 Android 提供 3 款原生桌面小工具（可於 `android-widgets/` 自由調整版面與樣式）：
* **今日任務小工具 (4x2 / 3x2)**：桌面即時呈現今日工作桌待辦項目、尺寸標籤與容量進度，附帶快速新增按鈕。
* **當前專注小工具 (2x1)**：大字置頂顯示目前標記為「現在」的焦點任務與預估耗時。
* **快速收集小工具 (2x1 / 4x1)**：一鍵從手機桌面呼叫輸入框，即刻將靈感或雜事捕捉至收集箱。

### 4. 緊急與重要四象限 (Eisenhower Matrix) 與隱形死線
系統全面整合艾森豪四象限管理法，並嚴格落實「零焦慮設計原則」：
* **四象限分類**：
  * **Q1 重要且緊急**：燃眉之急、即刻攻克。
  * **Q2 重要不緊急**：核心目標、長期價值推進（系統預設推薦核心）。
  * **Q3 緊急不重要**：突發瑣事、干擾打擾、快速消化。
  * **Q4 不重要不緊急**：低價值干擾、順便進行或考慮放生。
* **隱形死線機制 (Invisible Deadline)**：
  * 支援為任務填寫截止死線（可於快速收集或卡片象限選單中設定）。
  * **主介面卡片上絕不強制張貼死線字串或倒數計時**，徹底消除打開工作桌時的壓迫感與罪惡感。
  * 死線在後台安靜運作，當死線臨近（48 小時內）時自動加權，作為「幫我選」智慧決策的重要依據。
* **四象限矩陣總覽**：點擊頂部導航「四象限總覽」圖示，即可展開 2x2 宏觀矩陣檢視，自由調配任務象限並盤點死線。

### 5. 「幫我選」一鍵客觀自動決策 (Auto-Decide) - 100% 消除決策疲勞
無需再費神填寫冗長問卷！點擊「幫我選」，系統立即依據客觀條件**直接為您做決定並指派「現在做這個」**：
* **決策加權邏輯**：
  * **象限優先級**：Q1 (重要緊急) > Q2 (重要核心) > Q3 (緊急瑣事) > Q4。
  * **死線迫近加成**：今日/逾期 > 48 小時內 > 本週內。
  * **時段生理節律**：
    * 早晨/上午：偏好推進 Q1/Q2 的中大型深度專注任務。
    * 下午時段：穩定消化中小型推進任務。
    * 晚間/深夜：優先挑選 15-30 分鐘好消化的小型任務，避免深夜硬推大任務造成心理抗拒與拖延。
  * **今日工作桌優先**：優先鎖定今日桌待辦。
* **無痛切換**：自動將最佳項目設為「現在做這個」並置頂高亮，彈窗顯示清晰決策理由；亦提供「換一個」與「微調條件」選項。
* 純本機運算，零外部 API 請求、零 Token 洩漏風險，離線可用。

### 6. Google Tasks 與批次匯入
* 支援由 Google Takeout 匯出的 `Tasks.json` 檔案直接匯入。
* 支援複製純文字清單（一行一項）快速貼上。
* 可選擇過濾已完成項目，並依關鍵字或規則自動標記任務類型與尺寸。

### 7. 跨裝置手動同步
* **GitHub Gist 同步**：透過 Personal Access Token，於電腦與手機間雙向合併最新資料（依據時間戳記聰明解析）。
* **裝置代碼直傳**：免設定 Token，直接將本機資料轉換為單一同步字串，貼至另一裝置即可合併。

### 8. 隱私防護與外觀適配
* **本機 PIN 碼鎖定**：採用 Web Crypto API (SHA-256) 本機加密比對，防止公開部署或他人借用設備時窺探任務內容。
* **外觀風格**：深色模式（Deep Space Tech Dark），搭配 JetBrains Mono 等字型。
* **螢幕挖孔避讓**：提供頂部安全邊距調整滑桿，可針對 Zenfone 10 等具備前鏡頭挖孔的機型微調 Navbar 高度。

## 技術架構

* **前端核心**：純 HTML5、CSS3、Vanilla JavaScript（無第三方框架依賴）。
* **離線與安裝支援**：PWA (Service Worker + Web App Manifest)。
* **原生行動端封裝**：Capacitor 7 (Android)。
* **自動化工作流程**：GitHub Actions（自動部署 GitHub Pages 與打包 Release APK）。

## 本地開發與建置

### 1. 啟動本機預覽
專案為靜態 Web 應用，可直接透過任何靜態檔案伺服器執行：

```bash
# 使用 Python 內建伺服器
python -m http.server 8080

# 或使用 Node.js
npx serve .
```

開啟瀏覽器前往 `http://localhost:8080` 即可使用。

### 2. 打包 Web 靜態資源
將根目錄的核心網頁檔案同步至 `www/` 目錄：

```bash
node build.js
```

### 3. 封裝 Android APK
專案已配置 Capacitor 支援：

```bash
# 安裝依賴套件
npm install

# 同步資源至 Android 專案
npx cap sync android

# 使用 Android Studio 開啟
npx cap open android
```

若環境中已安裝 Android SDK 與 JDK 21，亦可直接使用 Gradle 指令建置：

```bash
cd android
./gradlew assembleDebug
```

產生的 APK 檔案位於 `android/app/build/outputs/apk/debug/app-debug.apk`。

## 資料安全性

本工具所有資料（包含任務項目、備註、個人設定與同步 Token）均僅儲存於使用者瀏覽器或本機設備的 LocalStorage 中。本專案完全不使用外部第三方 AI API，零資料外傳與外洩疑慮。
